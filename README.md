# Домашнee задание №1 по Systеm Dеsign
### **Задача**

Зоопарк — это сложная система, которая включает:
- множество видов животных;
- сотрудников;
- вольеры;
- модули для учета:
    - кормления;
    - медицинских осмотров;
    - выставок.

**Задача** — спроектировать программную подсистему, отражающую базовые аспекты функционирования зоопарка, применяя принципы SOLID для обеспечения расширяемости, читаемости и возможности сопровождения кода.

**Основная цель задания** — не столько просто реализовать полную систему, а сколько продемонстрировать грамотное применение архитектурных принципов SOLID в реалистичном, предметном контексте.

### **Реализация**
Реализованы интерфейсы кормления и мед. осмотров.

Реализован базовый класс животных Animal и два примера классов животных с реализацией интерфейсов.
Реализован базовый класс работников Employee и два примера классов работников.
Реализован класс вольера с возможностью размещения животных и вывода информации.
Реализованы классы для учета кормления, мед. осмотров, выставок.
Реализован класс ZooERP для проведения мед. осмотров, выставок, кормления.
В классе Main реализована проверка работы всех систем зоопарка.
